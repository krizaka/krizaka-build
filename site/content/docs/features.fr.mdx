Ce qu'une équipe Spring Boot 4 attend d'une bibliothèque de briques, et où en est Krizaka Java — honnêtement. Une ligne
**livrée** nomme les fichiers qui la prouvent, et le site ne se construit pas si l'un d'eux manque sur `main` ; une ligne
**partielle** ou **prévue** renvoie à l'issue qui suit le reste. L'audit derrière cette page est
[l'ADR-001](https://github.com/krizaka/krizaka-build/blob/main/docs/adr/ADR-001-krizaka-java-gap-audit.md).

Livré veut dire fusionné et testé. Les briques fusionnées depuis la dernière release arrivent sur Maven Central avec la
suivante : vérifie la version de chaque artefact sur la [carte des briques](/map).
