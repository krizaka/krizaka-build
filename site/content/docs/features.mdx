What a Spring Boot 4 team expects of a building-blocks library, and where Krizaka Java stands — honestly. A line marked
**shipped** names the files that prove it, and the site does not build if one of them is missing from `main`; a line
marked **partial** or **planned** links the issue that tracks the rest. The audit behind this page is
[ADR-001](https://github.com/krizaka/krizaka-build/blob/main/docs/adr/ADR-001-krizaka-java-gap-audit.md).

Shipped means merged and tested. The building blocks merged since the last release reach Maven Central with the next
one: check the version of each artifact on the [building blocks map](/map).
